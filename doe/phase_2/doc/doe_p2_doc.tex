\section{Focus Area, Rationale, and Stakeholder Relevance}
This project addresses the strategic siting and capacity sizing of clean energy microgrids and storage systems within power distribution grids. Siting decisions represent a high-stakes, combinatorial planning challenge under complex electrical constraints. To guide real planning outcomes, we model a multi-objective optimization problem that co-optimizes grid resilience ($C_{\rm R}$), capital installation cost ($C_{\rm I}$), and operational voltage control ($C_{\rm VC}$). 

The primary stakeholders and beneficiaries of this methodology include:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
  \item \textbf{Electric Utilities and ISOs:} Enables optimal capital allocation for grid assets and helps maintain power quality under dynamic load conditions.
  \item \textbf{Department of Energy (DOE):} Accelerates grid decarbonization and modernization mandates through quantum-enhanced optimization frameworks.
  \item \textbf{Local Communities:} Enhances energy security and resilience against catastrophic outages during extreme weather events.
\end{itemize}

\section{Technical Methodology and Hybrid Quantum Integration}
We implement a hybrid QAMOO~\cite{qamoo2025} and Multiverse~\cite{multiverse2023} optimization framework using a Benders decomposition layout solver. The architecture partition divides the optimization into a classical Master Problem (MP) and an AC power-flow Subproblem (SP), aligning with Benders principles~\cite{pasqal2024}. 

\subsection{Classical Benders Preprocessing (CPU)}
The Master Problem handles the discrete layout coordinates, selecting the binary portfolio of bus locations for asset placement ($\hat{x}^{(t)} \in \{0,1\}^N$). It is solved using CPLEX/DOcplex~\cite{cplex2024}. The candidate layout $\hat{x}^{(t)}$ is passed to the SP evaluator, which runs a classical AC power-flow simulation using \verb|pandapower|~\cite{pandapower2018}. If physical line limits (thermal branch loading $> 100\%$) or voltage limits ($0.95 \le V_j \le 1.05$ p.u.) are violated, the SP generates linear feasibility cuts:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
  \item \textbf{Line Overload Cuts:} For overloaded branches between bus $u$ and $v$: $x_u + x_v \le 1$.
  \item \textbf{Voltage Deviation Cuts:} For bus $w$ experiencing operational bounds violation: $x_w \le 0$.
  \item \textbf{Exact Vector Forbid (Fallback):} If specific buses cannot be isolated: $\sum_{i: \hat{x}_i^{(t)}=1} x_i + \sum_{i: \hat{x}_i^{(t)}=0} (1 - x_i) \le N - 1$.
\end{itemize}
These cuts compile iteratively ($T=5$) to form a set of linear constraints on the master layout solver.

\subsection{QUBO Penalty Mapping}
To embed feasibility constraints into the QAMOO quantum layer, we convert the collected cuts into quadratic penalty terms that modify the self-loop diagonals of the target Ising objective graphs:
\begin{equation}
  p_i = \lambda \cdot \hat{x}_i^{(t)}
\end{equation}
where $\lambda = 10.0$ is the penalty weight. This mutates the diagonal terms of the objective graphs to penalize infeasible portfolios, steering the quantum variational sampler away from voltage and thermal limit violations.

\subsection{Quantum Siting Optimization (QAMOO) and Error Mitigation}
Once the penalized graphs are compiled, we train a multi-objective QAOA ($p=3$ layers) optimized using COBYLA on a scalarized representation of the three objectives. The Pareto front is evaluated by executing batched sample runs of size $S=10$ using Dirichlet-distributed scalarization weights. 

To overcome physical device noise, we have implemented and integrated the client-side \verb|Samplomatic| error-mitigation pipeline using Qiskit's new \verb|Executor| primitive. This pipeline combines three error mitigation techniques:
\begin{enumerate}[leftmargin=*,noitemsep,topsep=0pt]
  \item \textbf{Probabilistic Error Cancellation (PEC):} Reconstructs noise-free expectation values by sampling from quasi-probability distributions of noisy circuits using Pauli Lindblad noise maps fetched via \verb|pauli_lindblad_maps|.
  \item \textbf{Shaded Lightcones (SLC):} Optimizes query budgets by decomposing the full circuit into causal cones and restricting mitigation operations to the active causal cones of target measured qubits.
  \item \textbf{Propagated Noise Absorption (PNA):} Classically propagates gate error rates through entangling layers and absorbs them to correct expectation biases in post-processing.
\end{enumerate}

\section{Data Modeling and Benchmarking Strategy}
Our data modeling strategy utilizes the standard IEEE 33-bus radial distribution system, a public and reproducible test grid. The model incorporates candidate sets for microgrid and storage asset placement across all buses under localized loads and weather-driven outage scenarios. 

To validate the quantum optimization performance, we benchmark Benders-QAMOO against two exact classical methods:
\begin{enumerate}[leftmargin=*,noitemsep,topsep=0pt]
  \item \textbf{CPLEX Weighted-Sum:} An exact classical solver executing 30 scalarized mixed-integer linear programming (MILP) evaluations.
  \item \textbf{Defining Point Algorithm (DPA):} An exact multi-objective integer programming algorithm. The quadratic terms are linearized by introducing auxiliary variables $z_{uv} = x_u x_v$ and solved via a compiled C++ binary (\verb|dpa-main|) under epsilon-constraints.
\end{enumerate}

The results show that integrating Benders cuts as static QUBO penalties dramatically improves quantum optimization. Benders-QAMOO achieved a hypervolume of $71.1870$ (compared to $6.2512$ for native QAMOO), reduced the IGD from $28.3398$ to $25.8634$, and improved the additive epsilon indicator $\epsilon^+$ from $24.5017$ to $22.9644$. 

Note that the exact classical benchmarks (CPLEX and DPA) collapse to a single Pareto point ($|{\rm PF}| = 1$). This is a direct mathematical consequence of the IEEE 33-bus system grid topology being a radial network (a tree graph). Since tree graphs are bipartite, a single bipartition configuration (and its complement) cuts every edge in the graph. Under a pure Max-Cut QUBO formulation, this bipartition simultaneously maximizes all three objectives, removing any trade-offs from the exact Pareto front. Similarly, because $|{\rm PF}| = 1$ for the exact methods, their spacing is mathematically undefined (${\rm N/A}$), whereas Benders-QAMOO with $|{\rm PF}| = 2$ has a spacing of $0.0000$ due to identical symmetric pairwise distances.

\section{Quantum Platform Justification and Resource Needs}
We request 3 hours of active runtime on IBM Quantum 156-qubit Heron-class QPUs (e.g., Kingston, Fez; 120-qubit Eagle-class as alternative) to execute our error-mitigated Benders-QAMOO workflow. Physical hardware execution is required because classical Tensor Network simulation (Qiskit Aer Matrix Product State) cannot reproduce physical noise. Heron's scale supports direct variable encoding of grid topologies up to 156 bus widths, and its $>99\%$ 2-qubit gate fidelity and low cross-talk are necessary for the Samplomatic PEC maps to extract physical signals (which fail on noisier Eagle systems). The runtime will support 50 to 100 iterative jobs per workflow (QPU execution is reserved strictly for quantum Pareto evaluations, with QAOA parameters pre-trained classically). Each workflow job executes 320 circuits (10 Pareto points $\times$ 32 twirling randomizations) at 125 shots per circuit (40,000 shots total), integrated natively using Qiskit Executor primitives to bypass the standard 10 min/month cap.


\section{Gap Analysis and Implementation Roadmap}
While Phase 2 validated the feasibility-penalized QAMOO workflow, the following gaps are slated for our Phase 3 roadmap:
\begin{itemize}[leftmargin=*,noitemsep,topsep=0pt]
  \item \textbf{Online Hybrid Benders Loop:} Transition from the current offline classical preprocessor to an online iterative loop where the QPU directly executes the Master Problem QUBO solver in each iteration.
  \item \textbf{Exact Constraint Penalization:} Replace the heuristic diagonal penalty weight ($\lambda$) with exact quadratic penalty terms representing the slack variables of inequality constraints.
  \item \textbf{Optimality Cuts:} Implement dual-based optimality cuts to bound and optimize objective function values, moving beyond feasibility-only cuts.
  \item \textbf{Physical QPU Scaling:} Execute the full Samplomatic error-mitigated pipeline on the Heron hardware.
\end{itemize}
